# Bharat360

**India's progress, measured through data.**

Bharat360 is a modern data storytelling platform that transforms complex public datasets into interactive visual experiences. Instead of overwhelming users with raw statistics, it presents meaningful insights through dynamic dashboards, comparisons, AI-generated summaries, and intuitive visualizations that make national development data easy to understand.

The platform combines trusted international datasets with clean UI, interactive charts, contextual explanations, and guided exploration to help users discover not just *what* the data says, but *why* it matters.

---

## Overview

Bharat360 is designed around the idea that data should tell a story.

Users can explore India's progress over time, compare it with leading countries, understand trends through AI-generated insights, and dive deeper into the datasets behind every visualization.

Every dashboard focuses on making information accessible by combining visual analytics with contextual explanations instead of simply displaying numbers.

---

## Key Features

• Interactive domain dashboards with responsive visualizations
• Global dataset search and centralized dataset repository
• AI-assisted insights and editorial data storytelling
• Historical trend analysis and country comparison
• Interactive world map for global benchmarking
• Interactive state map (demonstration with mock state-level data)
• Context-aware tooltips and metric explanations
• Dataset downloads with source attribution
• Dashboard export as PDF
• Responsive design with Dark & Light mode

---

## Data Storytelling Approach

Rather than presenting isolated charts, Bharat360 guides users through a narrative.

Each section answers questions such as:

- What changed?
- Why did it change?
- How does India compare globally?
- Which countries perform better?
- What practices contribute to their success?
- Which datasets support these findings?
- Where can users explore the original data?
- Where does the data come from?
  
This approach transforms dashboards from analytical tools into educational experiences.
